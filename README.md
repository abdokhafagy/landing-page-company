# Summit Edge Consulting - Landing Page\n\nA premium, bilingual (English/Arabic) landing page for a fictional business consulting firm. Features dark/light mode, responsive design, and modern web technologies.\n\n## ✨ Features\n\n### Core Functionality\n- **Bilingual Support**: Full English/Arabic translation with RTL layout\n- **Dark/Light Mode**: Theme toggle with system preference detection\n- **Responsive Design**: Optimized for desktop, tablet, and mobile\n- **Accessibility**: WCAG AA compliant with proper ARIA labels\n- **Performance**: Optimized images, lazy loading, and efficient animations\n\n### Sections\n1. **Hero Section**: Compelling headline with CTAs and company statistics\n2. **About Section**: Company story with features and milestones\n3. **Services Section**: 5 consulting services with hover effects\n4. **Portfolio Section**: Filterable project showcase with modal details\n5. **Testimonials Section**: Auto-rotating client feedback carousel\n6. **Contact Section**: Validation-enabled form with multiple contact methods\n7. **Footer**: Company info, links, and social media\n\n### Interactive Elements\n- Smooth scroll navigation with scrollspy\n- Portfolio filtering and modal display\n- Testimonials carousel with touch/swipe support\n- Contact form with real-time validation\n- Newsletter popup with dismissal persistence\n- Back-to-top button\n- Mobile hamburger menu\n\n## 🚀 Quick Start\n\n1. **Open in Browser**: Simply open `index.html` in any modern web browser\n2. **Live Server** (Recommended): Use VS Code Live Server extension for hot reload\n3. **Local Server**: Serve files using Python, Node.js, or any HTTP server\n\n```bash\n# Python 3\npython -m http.server 8000\n\n# Node.js (http-server)\nnpx http-server .\n\n# Open browser to http://localhost:8000\n```\n\n## 📁 Project Structure\n\n```\nLanding-page/\n├── index.html                 #
